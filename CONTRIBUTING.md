# Contribuer à CyberShield

Point d'entrée : https://github.com/HashCode-Reboot/hashcode-contributors.

Le projet est défensif. Toute expérimentation doit être autorisée et menée sur des environnements contrôlés. Ne pas publier de secrets, données personnelles ou procédures offensives non nécessaires.

Une PR décrit menace traitée, architecture, tests, limites, sécurité et impact attendu.
